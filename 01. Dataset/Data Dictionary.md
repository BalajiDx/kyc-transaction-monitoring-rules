# Data Dictionary

All data is **synthetic**, generated by `generate_dataset.py` (seed 11). No real customer, bank or transaction data is used.
Period **1 Jan - 31 Dec 2024**, amounts in INR. Country codes `XA`, `XB`, `XC` are placeholders for a bank's high-risk
jurisdiction list, not real countries.

|---|---|---|

| Occupation | text | Salaried, Self-Employed, Business Owner, Student, Retired, Homemaker |

| State | text | |

| PANAvailable / AadhaarVerified / AddressProofOnFile | 0/1 | KYC document flags |

| LastKYCReviewDate | date | Last periodic KYC update |

## Accounts (1,800 rows)
One account per customer: `AccountID`, `CustomerID`, `AccountType` (Savings / Current), `OpenDate`.

## Planted Scenarios (51 rows)
The generator plants five suspicious patterns into otherwise normal activity: **Structuring (14), Pass-through (rapid in/out) (12), Income mismatch (10), Funnel account (many senders) (8), High-risk jurisdiction (7)**.
About a quarter of the structuring and a fifth of the pass-through cases were planted in an *evasive* form (deposits spread out, money held 3-4 days) to show what fixed thresholds miss.
It also adds **legitimate look-alikes** that are *not* listed here: shops paid by many UPI customers, one-off property-sale proceeds used to buy a house, and cash-heavy small businesses.
This file is used **only** by `rules_engine.py` to measure the rules afterwards. The rules never read it.
